# LQL v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 LQL 中实现加载器、Modrinth 内容安装管理、mrpack 安装与安全更新。

**Architecture:** 主进程扩展受管下载、加载器、资源、整合包与文件事务服务。沿用现有 typed IPC 和 Vue/Naive UI；单一任务入口协调所有写入，与游戏进程互斥。

**Tech Stack:** Electron / Vue 3 / TypeScript / Naive UI / XMCL / Vitest / Playwright。

**Spec:** docs/superpowers/specs/2026-11-16-lql-v0.2-design.md

## Global Constraints

- 支持 Windows 10/11 x64；不自动提交、推送、创建分支或对外发布。
- 原版实例、账号、本地角色、设置、日志和现有用户数据必须保持可用。
- 一实例只能有一种通用加载器；来源不支持的组合必须拒绝。
- 首个资源平台为 Modrinth；CurseForge 为后续接入项。
- 所有真实下载与启动使用隔离验收目录。
- 本轮同一时间执行一个写任务；取消必须等待写入与子进程结束。

## Review Focus

1. 更新过程中断：持久事务恢复文件与清单，再允许启动。
2. Windows 大小写、保留名、ZIP 链接与重复条目：拒绝越界或有歧义输入。
3. 固定版本 required 依赖与现有项目冲突：不得安装不兼容依赖或静默覆盖。
4. 加载器生成库没有官方文件尺寸或摘要：使用官方发布校验信息及安装器验证，不能捏造摘要。
5. 取消后关闭应用：等待安装器及所有活跃写入完成。

## File Structure

- src/shared/contracts.ts：加载器、资源、计划、任务契约。
- src/main/game/loaders.ts：官方加载器目录、安装与派生版本。
- src/main/game/download.ts：SHA-1/SHA-512 校验与受限重定向。
- src/main/content/catalog.ts：Modrinth 查询、版本和依赖计划。
- src/main/content/archive.ts：有界 ZIP 与 mrpack 校验。
- src/main/content/transactions.ts：文件事务、备份、恢复。
- src/main/content/service.ts：实例内容、整合包与任务编排。
- src/main/ipc.ts、src/preload/index.ts、src/main/index.ts：业务绑定与互斥。
- src/renderer/views/{DiscoverView,ContentView,TasksView}.vue：资源、实例内容、任务。
- tests/content/*、tests/game/loaders.test.ts、tests/e2e/content.spec.ts：异常逻辑、边界、真实界面。
