# 本地角色补充范围

用户已确认：添加无需微软登录的本地角色，继续交付 Windows EXE。此范围取代 v0.1 原设计中排除本地身份的约束，保留已有微软设备代码流程。

- 在账号页使用 Naive UI 表单添加昵称，3–16 位 ASCII 字母、数字或下划线；去除两端空白，同名比较忽略大小写，UUID 计算保留大小写。
- 使用 Java `UUID.nameUUIDFromBytes` 相同的 MD5 / version 3 / RFC variant 规则，以 UTF-8 `OfflinePlayer:<name>` 生成稳定 UUID。独立 `local:` ID 避免与微软账号碰撞。
- 本地角色保存在原子配置中，旧配置缺少角色列表时迁移为空列表；损坏的现有角色数据保留并报错。无需 Windows 凭据加密支持。
- 账号快照标明身份类型。创建即选择；支持切换和移除，移除不删除存档。相同大小写的昵称重新创建仍得到相同 UUID。
- 本地启动不调用微软认证，使用本地身份和 legacy 参数；微软账号失败时不自动降级成本地角色。用于单人游戏及允许离线身份的服务器，不提供正版服务器、Realms 或在线皮肤认证。

执行与验证：先用存储及启动边界测试验证失败，再实现主进程与 IPC，接入真实组件表单并验证重启持久化；随后重新构建安装版与单文件版，执行安装版 E2E，并尝试现有官方基线的真实本地启动。真实游戏主菜单和真实微软授权分别记录，不能互相替代。
